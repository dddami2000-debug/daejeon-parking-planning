# User Flow

## 전체 흐름

```mermaid
flowchart TD
    A[앱 최초 접속] --> B{위치 권한 허용?}
    B --> C[심리테스트 화면]

    C --> D{테스트 건너뛰기?}
    D -- 예 --> H[홈·장소 탐색]
    D -- 아니오 --> E[질문 답변 제출]
    E --> F{AI 분석 성공?}
    F -- 예 --> G[취향 결과 화면]
    F -- 아니오 --> G2[규칙 기반 취향 결과]
    G --> H
    G2 --> H

    H --> I{지도 API 정상?}
    I -- 예 --> J[추천 축제·지도 마커]
    I -- 아니오 --> J2[지도 대체 장소 목록]

    J --> K[장소 선택]
    J2 --> K
    K --> L[장소 상세 바텀시트]
    L --> M[주차 플랜 화면]

    M --> N[방문 날짜·입출차 시간 입력]
    N --> O{주차 API 정상?}
    O -- 아니오 --> O2[저장 JSON fallback]
    O -- 예 --> P{후보 3개 확보?}
    O2 --> P

    P -- 아니오 --> Q[반경 5km 확장]
    Q --> R[주차장 1·2·3순위 카드]
    P -- 예 --> R

    R --> S[길안내 시작]
    S --> T{기본 내비앱 저장됨?}
    T -- 아니오 --> U[내비앱 선택·저장]
    U --> V{딥링크 성공?}
    T -- 예 --> V

    V -- 예 --> W[외부 내비앱 길안내]
    V -- 아니오 --> W2[웹 지도 검색]

    W --> X{주차장 만차?}
    X -- 아니오 --> Y[주차 완료]
    X -- 예 --> Z{다음 후보 있음?}
    Z -- 예 --> V
    Z -- 아니오 --> Z2[후보 소진 안내]
    Z2 --> M
```

## 구간별 설명

### 1. 취향 분석 온보딩
최초 접속 → 위치 권한 처리 → 심리테스트 → AI 또는 규칙 기반 취향 결과

### 2. 장소 발견 및 추천
홈 → 추천 축제/지도 → API 실패 시 대체 목록 → 장소 상세

### 3. 주차 플랜
방문 시간 입력 → 주변 후보 수집 → 3개 미만이면 5km까지 확대 → 1·2·3순위 표시

### 4. 길안내 및 만차 전환
내비게이션 선택 → 딥링크 → 만차 시 다음 후보 → 모두 소진 시 재탐색

### 5. 장애 대체
외부 API 실패, 지도 실패, 위치 권한 거절 상황에서도 저장 데이터와 기본값으로 핵심 흐름을 유지합니다.
