# Requirements

## R-TABLXR — 취향 분석 온보딩
**중요도:** High  
**상태:** Todo

방문 운전자가 첫 접속에서 나들이 취향을 확인하거나 테스트를 건너뛰고 서비스 탐색을 시작하는 영역입니다.

포함:
- 상황형 심리테스트
- 네 가지 취향 유형 분류
- 선택형 성별·연령대 기본 정보
- 결과의 브라우저 저장
- 재테스트

제외:
- 회원 식별
- 민감정보 수집

### 완료 조건
- 첫 접속 시 테스트와 건너뛰기 제공
- 테스트 후 네 가지 취향 점수·주 유형·추천 이유 표시 및 새로고침 후 유지
- 네 유형의 전체 비율을 저장하고 규칙 기반 추천 계산에 사용
- 성별·연령대는 미응답을 허용하고 브라우저 안에서만 추천 계산에 사용

## R-FGBJMG — 장소 발견 및 추천
**중요도:** High  
**상태:** Todo

대전의 축제와 랜드마크를 취향, 현재 위치, 행사 기간에 따라 탐색하고 방문 장소를 결정하는 영역입니다.

### 완료 조건
- 모든 추천 결과에 최소 한 가지 추천 근거 표시
- 축제와 랜드마크를 지도·목록에서 시각적으로 구분
- 상세 화면에 기간, 운영시간, 소개, 거리 및 주차 플랜 진입 제공

---

## R-CVFEHL — 주차 플랜 및 요금 추천
**중요도:** High  
**상태:** Todo

방문 시간에 맞춰 목적지 주변 주차장을 비교하고 1·2·3순위 계획을 제공하는 영역입니다.

포함:
- 후보 수집
- 운영 조건 검증
- 예상 요금 계산
- 추천 순위 및 근거

제외:
- 예약·결제
- 모든 주차장의 자동 만차 판정

### 완료 조건
- 날짜·시간 변경 시 예상 요금과 순위 재계산
- 최대 3개 후보에 주차장 정보·거리·운영시간·요금·추천 근거 표시
- 후보 부족 시 5km까지 반경 확장

---

## R-ZFVGGZ — 길안내 및 만차 전환
**중요도:** High  
**상태:** Todo

외부 내비게이션으로 추천 주차장 길안내를 시작하고, 만차 시 다음 순위로 빠르게 전환합니다.

### 완료 조건
- 최초 길안내 시 내비게이션 앱 선택 및 저장
- 만차 시 현재 후보 제외 후 최대 2회 탭으로 다음 후보 안내
- 딥링크 실패 시 웹 지도 검색 링크 제공

---

## R-MRSEJG — 외부 데이터 대체 및 반응형 경험
**중요도:** High  
**상태:** Todo

외부 API 장애나 위치 권한 거절 상황에서도 핵심 탐색과 주차 플랜을 계속 사용할 수 있도록 합니다.

### 완료 조건
- 축제·관광·주차 API 실패 시 저장 데이터로 핵심 시연 가능
- 위치 권한 거절 시 대전시청을 기본 위치로 사용
- 360px 너비에서 가로 넘침 없이 표시
- 주요 터치 영역 44px 이상
