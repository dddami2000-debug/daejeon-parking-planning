# PRD

## 제품 개요

**제품명:** 대전 주차 추천 서비스

**카테고리:** Lifestyle

**주요 디바이스:** 모바일 웹, 데스크톱 웹

**주요 사용자:** 대전과 근교 축제를 자가용으로 방문하는 시민·관광객

## 목표

대전과 근교 축제 방문자가 취향과 현재 위치에 맞는 행사를 빠르게 발견하고, 예상 주차비와 만차 대안까지 포함한 주차 계획을 세워 바로 출발하도록 돕습니다.

## 배경

대전과 근교의 축제 정보와 주변 주차장 정보가 여러 채널에 흩어져 있어 장소 발견과 주차 계획에 반복적인 검색이 필요합니다.

축제 기간에는 가까운 주차장이 만차일 수 있어 운전 중 대안을 다시 검색해야 하는 부담도 큽니다.

24시간 해커톤 MVP에서는 **심리테스트 → 장소 추천 → 주차장 3순위 → 길안내 → 다음 순위 전환**까지의 흐름을 시연합니다.

## 사용자 문제

- 오늘 갈 만한 대전과 근교 축제를 취향과 거리 기준으로 비교하기 어렵습니다.
- 목적지를 정한 뒤에도 주차장 위치, 운영시간, 요금 등을 따로 확인해야 합니다.
- 1순위 주차장이 만차일 경우 운전 중 다음 후보를 다시 검색하기 어렵습니다.

## 해결 방안

- AI 취향 분석, 현재 위치, 행사 기간을 활용한 축제 추천
- 지도 및 장소 상세 정보 제공
- 방문 날짜·입출차 시간을 반영한 주차장 1·2·3순위 제공
- 예상 주차비 및 추천 근거 표시
- 만차 신고 시 저장된 내비게이션 앱으로 다음 후보 즉시 안내
- 외부 API 실패 시 저장 JSON과 규칙 기반 분석으로 핵심 흐름 유지

## 차별점

일반 지도 검색과 달리 다음 기능을 하나의 사용자 여정으로 연결합니다.

1. 취향 기반 장소 발견
2. 운영시간을 반영한 예상 주차비 계산
3. 주차장 우선순위 추천
4. 만차 시 다음 순위로 즉시 전환

실시간 잔여면 데이터가 없는 경우에도 사용자 주도 만차 전환으로 대안을 제공합니다.

## 주요 타겟

- 대전 시민 및 관광객
- 자가용 운전자
- 가족·연인·친구와 나들이를 계획하는 사용자
- 주차비 절약에 민감한 대학생·사회초년생
- 행사 시간과 주차 가능 시간을 함께 확인하고 싶은 사용자

## 대표 시나리오

사용자는 첫 접속에서 상황형 심리테스트를 완료하거나 건너뜁니다.

홈에서 추천 축제 슬라이더와 지도 버블을 통해 장소를 탐색하고, 상세 화면에서 행사 기간·운영시간·추천 이유를 확인합니다.

주차 플랜 화면에서 방문 날짜와 입출차 시간을 입력하면 1·2·3순위 주차장과 예상 요금이 표시됩니다.

사용자는 1순위 주차장을 선택해 네이버지도·카카오내비·티맵 중 저장된 앱으로 길안내를 시작합니다.

도착 후 만차라면 `만차예요, 다음 주차장` 버튼을 눌러 같은 내비게이션 앱으로 다음 순위 후보 안내를 시작합니다.

## KPI

- 첫 접속 후 **3분 이내** 장소 추천 및 주차장 3순위 확인 완료율
- 1순위 → 2순위 주차장 길안내 전환을 **최대 2회 탭** 안에 완료
- 모든 추천 결과에 추천 근거 표시
- 외부 API 실패 상황에서도 핵심 시연 흐름 완료

## 주요 리스크

- 공공 API의 형식 및 가용성
- 지도 API Key 설정
- 내비게이션 딥링크의 기기별 동작 차이
- 실시간 주차 잔여면 데이터 부족
- OpenAI 응답의 비정형성
- 24시간 해커톤에서의 기능 과다

## 대응

- API별 변환 계층 구성
- 저장 JSON fallback 데이터 준비
- AI 응답 스키마 검증 + 규칙 기반 fallback
- 내비게이션 딥링크 실패 시 웹 지도 검색 링크 제공
- P0 흐름 완성 전 P1 기능 구현 금지
