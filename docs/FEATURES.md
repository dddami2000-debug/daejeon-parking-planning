# Features

## F-CSITRQ — 심리테스트 및 취향 결과
상황형 질문에 답해 네 가지 나들이 취향 유형 비율과 설명을 확인합니다.

- 질문: 약 5개
- 결과: 주 유형, 네 유형 점수, 최대 3개 태그, 80자 이하 추천 이유
- 저장: `daejeonMap.personalityResult`
- 실패 시: 답변별 규칙 기반 점수표 사용
- 네 유형 점수 합계는 100

---

## F-CNHTDW — 지도 기반 장소 탐색
추천 축제 슬라이더와 지도에서 대전 축제·랜드마크를 탐색하고 상세 정보를 확인합니다.

- 위치 권한 거절 시 대전시청 좌표 사용
- 종료된 축제 기본 목록 제외
- 지도 API 실패 시 장소 카드 목록 제공
- 취향·거리·행사 기간·방문 가능 여부로 정렬

---

## F-YVTTIN — 추천 점수 및 근거 생성
사용 가능한 데이터만으로 장소 추천 점수를 계산합니다.

- 취향
- 거리
- 축제 마감 임박도
- 현재 방문 가능 여부
- 지원되는 경우 혼잡도

데이터가 없는 항목은 가중치 분모에서 제외합니다.

기본 거리 반경은 20km입니다.

---

## F-FPNZDX — 주차장 순위 및 요금 계산
방문 날짜 및 당일 입출차 시간을 입력해 주차장 최대 3개를 비교합니다.

평가 요소:
- 예상 요금
- 차량 이동시간
- 도보 거리
- 이용 가능 시간
- 총면수
- 제공되는 경우 잔여면수

기본 검색 반경은 3km이며, 부족하면 5km까지 확장합니다.

---

## F-FFBBOE — 실시간 주차 상태 표시
실시간 잔여면 데이터가 있는 주차장의 현재 상태를 표시합니다.

- 데이터가 없으면 `실시간 정보 없음`
- 실시간 데이터가 없다는 이유로 후보에서 제외하지 않음
- 제공되는 후보끼리만 보조 가점으로 사용

**중요도:** Low

---

## F-WJRMZM — 외부 내비게이션 길안내
주차장을 목적지로 외부 내비게이션 앱을 실행합니다.

지원 앱:
- 네이버지도
- 카카오내비
- 티맵

선택 앱은 `daejeonMap.preferredNavigation`에 저장합니다.

딥링크 실패 시 해당 서비스의 웹 지도 검색 링크를 사용합니다.

---

## F-NYOCZB — 만차 시 다음 후보 전환
현재 주차장이 만차이면 현재 세션에서 해당 후보를 제외하고 다음 순위 주차장을 안내합니다.

- 같은 내비게이션 앱 사용
- 만차 제외는 현재 세션에만 적용
- 실시간 잔여면이 없다는 사실만으로 만차라고 추정하지 않음
- 모든 후보 소진 시 주변 후보 재계산 또는 지도 검색 제공

---

## F-RBBFYB — 장애 대체 및 반응형 화면
외부 API 장애에도 저장 JSON과 기본값으로 핵심 흐름을 유지합니다.

- 위치 권한 거절 → 대전시청
- 실시간 주차 API 실패 → `실시간 정보 없음`
- 지도 실패 → 대체 목록
- API Key는 프런트엔드 소스에 포함하지 않음
- 모바일 360px에서도 가로 넘침 없이 표시
- 주요 버튼 터치 영역 44px 이상
