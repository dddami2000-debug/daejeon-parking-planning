# 대전콕 🅿️

> 이번 주말 갈 곳부터 주차까지 한 번에

[서비스 열기](https://daejeon-parking-planning.vercel.app)

## 문제

대전과 근교의 축제를 방문할 때 공영·노상·공공기관 주차장 정보가 여러 곳에 흩어져 있습니다. 방문자는 행사장까지의 거리, 운영시간, 예상 주차비를 직접 비교해야 하고, 현장에서 1순위 주차장이 만차이면 다시 검색해야 합니다.

## 해결

`대전콕`은 차를 타고 대전과 근교의 축제를 방문하려는 사용자를 위한 서비스입니다. 목적지가 없는 사용자는 세 가지 방문 조건으로 갈 곳을 고르고, 목적지가 정해진 사용자는 바로 검색한 뒤 실제 방문 시간에 운영하는 주차장까지 이어서 비교할 수 있습니다.

## 핵심 기능

- `갈 곳 추천받기`와 `목적지가 정해졌어요` 두 가지 진입 흐름
- 동행·활동·이동 조건만 묻는 3문항 방문조건 설정
- 퍼센트 점수 대신 운영 일정·거리·선택 활동을 설명하는 추천 이유
- 취향·거리·일정을 가중 합산한 내부 정렬 점수와, 같은 주제·지역이 몰리지 않게 하는 추천 다양성 보정
- 축제 선택 시 실제 지역, 일정, 현재 상태, 핵심 프로그램, 입장·예약, 우천·취소, 공식 출처와 업데이트 시각 제공
- 선택한 시간 전체에 운영하며 요금을 계산할 수 있는 주차장만 추천
- 거리 우선·가격 우선·대형 주차장 우선 기준과 예상 주차비 산출 근거 제공
- 지도 위 추천 주차장과 주변 주차장 표시, 개별 주차장 정보 확인
- 정보가 불확실한 후보의 제외 사유와 실시간 혼잡도 미제공 상태 표시
- 네이버지도·카카오맵·티맵 등 외부 내비게이션 길안내 연결

## 추천 기준

축제 추천 순위는 세 가지 신호를 가중 합산해 정합니다.

| 신호 | 가중치 | 기준 |
| --- | --- | --- |
| 취향 | 60% | 방문 조건에서 계산한 취향 점수 |
| 거리 | 25% | 현재 위치(또는 대전 중심)로부터의 거리 |
| 일정 | 15% | 여행 날짜를 고르면 그 기간, 고르지 않으면 오늘 기준 |

거리 점수는 전국 축제를 다루므로 한 지점에서 0점으로 끊지 않고 구간별로 이어집니다. `0~10km`는 100→85, `10~50km`는 85→65, `50~150km`는 65→40, `150~300km`는 40→20이며, 300km 밖도 20점에서 완만하게 낮아지되 최소 5점을 유지합니다. 위치를 알 수 없으면 중립값 50을 씁니다.

**이 가중치와 구간값은 초기 가설이며, 향후 상세 조회율·즐겨찾기율로 검증해 조정합니다.** 계산된 점수는 정렬에만 쓰고 화면에는 숫자 대신 `취향에 잘 맞아요`, `여행 기간에 열려요` 같은 근거 문구를 표시합니다. 상세 조회(1점)와 즐겨찾기(8점)는 30일 반감기로 개인화에 반영하되 최종 점수의 45%를 넘지 않습니다.

## 데이터와 기술

| 구분 | 사용 데이터·기술 | 용도 |
| --- | --- | --- |
| 축제 | 한국관광공사 TourAPI 지역축제 정보 | 진행 중·예정 축제의 일정과 장소 제공 |
| 주차장 | 대전광역시 주차장 정보·공유누리 | 공영·노상·공공기관 주차장 위치·요금·운영·규모 정보 제공 |
| 지도 | Naver Maps JavaScript API | 지도, 장소·주차장 마커 표시 |
| 백엔드 | Vercel Serverless Functions | 공공데이터 수집 및 API 제공 |
| 데이터베이스 | Supabase | 축제·주차장 정제 데이터 저장 |

공유누리 공공기관 주차장은 API 승인·데이터 품질을 확인 중이며, 안정화 후 주차장 추천 데이터에 포함할 예정입니다.

## 데이터 처리 방식

공공데이터는 브라우저가 아니라 Vercel Functions에서 수집해 Supabase에 저장합니다. 따라서 공공데이터 인증키와 Supabase Secret Key가 클라이언트에 노출되지 않습니다.

- `GET /api/places` — 축제 조회
- `GET /api/parking?lat=...&lng=...` — 목적지 주변 주차장 및 예상 요금 조회
- `GET|POST /api/sync?dataset=festival|parking|sharenuri` — 데이터 수집·동기화

축제 데이터에 좌표가 없을 때는 주소를 좌표화해 지도 표시를 보완합니다. 최신 장소나 주차장 API 호출이 실패하면 이전 값을 최신 정보처럼 표시하지 않고, 로딩 실패 또는 샘플 데이터 상태를 화면에 명확히 알립니다.

## 실행 방법

첫 실행 전 Vercel 프로젝트의 환경 변수를 로컬로 받아옵니다. 실제 키는 Git에 커밋하지 않습니다.

```bash
cd prototype
vercel env pull .env.local
vercel dev
```

브라우저에서 Vercel CLI가 안내하는 로컬 주소를 열면 서버리스 API까지 포함해 확인할 수 있습니다.

필수 환경 변수 이름은 [`prototype/.env.example`](prototype/.env.example)에 정리되어 있습니다. Production과 Preview 환경에 모두 등록하며, 수집 작업은 `CRON_SECRET`으로 보호합니다.

## UI

프로토타입은 `@seed-design/css` 2.4.0의 공식 토큰을 사용하며, 프로젝트별 화면 조정은 [`prototype/seed-theme.css`](prototype/seed-theme.css)에서 관리합니다. 모바일에서는 화면 전체를 사용하고, 데스크톱에서는 같은 모바일 화면을 아이폰 형태의 미리보기 프레임 안에 표시합니다.

## 24시간 MVP 범위

**두 가지 진입점 → 3문항 방문조건 또는 목적지 검색 → 근거가 보이는 장소 추천 → 사실 중심 상세 정보 → 검증된 주차 플랜 → 길안내**

실시간 잔여 주차면은 모든 공영·노상 주차장에서 제공되지 않으므로 혼잡도를 추정하지 않습니다. 운영시간·요금·주차면수 중 확인되지 않은 값은 `0원`이나 `여유`로 치환하지 않고 `확인 필요`로 표시하거나 해당 기준에서 제외합니다.
